# 从基金销售到资本市场退出：基金与资本市场法律案例集

> **状态：进行中（Portfolio Project / Work in Progress）**

本项目以一个贯穿三个模块的虚构案例为主线，展示如何把公开法律规则、交易文件与业务事实转化为可执行的法律审查、风险判断和整改方案。

## 1. 项目主线

**模块 A｜公募基金销售适当性**  
投资者识别 → 风险测评 → 产品评级 → 匹配校验 → 风险揭示 → 留痕 → 回访/投诉

**模块 B｜私募基金募投管退**  
基金设立 → 募集/准入 → 法律尽调 → 交易文件 → 交割 → 投后 → 退出

**模块 C｜资本市场 IPO**  
业务事实 → 尽调发现 → 法律问题 → 整改 → 风险披露 → 申报/审核

## 2. 我想证明的能力

- 把监管要求转化为业务流程和审查清单；
- 阅读并拆解基金、投资和资本市场文件；
- 用“事实—规则—风险—控制—证据”完成法律分析；
- 输出法律备忘录、尽调清单、风险登记表和英文摘要；
- 对结论保留来源、版本、访问日期和假设边界。

## 4. 统一分析方法

```text
业务事实
→ 文件/证据
→ 适用规则
→ 法律义务
→ 风险判断
→ 控制措施
→ 验收证据
→ 剩余风险
```

所有重大结论尽量同时关联：
1. 一个事实编号；
2. 一个规则编号；
3. 一个风险编号；
4. 一项整改措施；
5. 一项验收证据。

本项目为个人学习与求职作品集。虚构主体、基金产品、交易安排及部分样例材料仅用于模拟；涉及真实规则、案例或公开披露文件时，以公开来源为准。本项目不构成法律、投资、税务或合规意见。
