# Writing Guide

每份 memo 尽量使用同一骨架：

1. Executive Summary
2. Facts
3. Questions Presented
4. Short Answers
5. Applicable Rules
6. Analysis
7. Risks and Alternatives
8. Recommendations
9. Assumptions and Limitations
10. Sources

写作原则：
- 先结论、后分析；
- 不把“最佳实践”写成“法定义务”；
- 不把“风险存在”写成“违法已成立”；
- 对事实缺口明确写“待核实”；
- 每个高风险写责任人、期限、验收证据。
