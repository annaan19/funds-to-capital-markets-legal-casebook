# Common Risk Taxonomy｜统一风险分类

| 类别 | 模块 A | 模块 B | 模块 C |
|---|---|---|---|
| 客户/投资者/股东保护 | 适当性、风险揭示 | LP 准入、关联交易 | 股权清晰、少数股东保护 |
| 信息披露 | 宣传、定期披露 | LP 报告、重大事项 | 招股书、问询回复 |
| 合同风险 | 销售/代销协议 | LPA、TS、投资协议 | 重大合同、历史融资文件 |
| 数据与科技 | 线上销售留痕 | 被投企业数据尽调 | 数据、AI 与网络安全披露 |
| 行政/争议风险 | 误导销售、投诉 | 募集、利益冲突、回购 | 虚假陈述、处罚、诉讼 |
| 退出风险 | 赎回/投诉 | 回购、清算、IPO | 锁定、减持、披露 |
